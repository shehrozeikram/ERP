2
End-to-End Process Flow
17 steps across 5 phases — click each phase to expand
📋
Phase A — Project Setup & Planning
Create master project, zones, sub-projects, define WBS, prepare BOQ, get budget approved
▼
01
Create Master Project
Create "Taj Residencia" as a master project (isMasterProject: true). This is the top-level container — all 3 zones roll up into this.
Director / PM ConstructionProject.create()
▼
02
Create Zone Sub-Projects (Infra / Commercial / Villas)
Create 3 zone-level sub-projects with parentProject pointing to master. Set projectType = Infrastructure, Commercial Building, Villa. Each zone is also isMasterProject: true so blocks roll up into them.
Project Manager ConstructionProject.create()
▼
03
Create Block Sub-Projects (Gardenia, Iris, Boulevard Tower...)
Each block from MRM's spreadsheet becomes a sub-project under its zone. These are the leaf-level projects where actual work happens. parentProject → zone project. isMasterProject: false.
Project Manager ConstructionProject.create()
▼
04
Define Phases & Tasks (WBS)
For each block project, create the task hierarchy: Phase (level 0: Civil Works, Water Supply, etc.) → Tasks (level 1: Foundation, Earthwork, etc.) → Sub-Tasks (level 2: specific activities). This is MRM's Activity Level 3 + 4.
Costing Manager (MRM) ProjectTask.create()
▼
05
Prepare BOQ (Bill of Quantities)
Create BOQ documents (ProjectBOQ headers) per work category. Add line items (BOQItem) with quantities, unit prices, phases, categories. Items are grouped by phase (Civil, Water, etc.) and categorised by sub-work. This is MRM's core "INPUT INTERFACE — BOQ".
Costing Manager (MRM) ProjectBOQ + BOQItem.create()
▼
06
Set Budget Categories & Milestones
Define budget breakdown (Civil Works, Electrical, Plumbing, etc.) and billing milestones with trigger percentages. Budget = sum of BOQ. Milestones tie to billing events.
Costing Manager project.budgetCategories[]
project.milestones[]
▼
Budget Approval Gate
✓ PM + Director Approve → Proceed ✗ Rejected → Revise BOQ
▼
07
Budget Approved & Baseline Set
Budget status moves from Draft → Submitted → Approved. totalApprovedBudget is locked. All future actuals are compared against this baseline for variance analysis.
Director PUT /budget-status { action: 'approve' }
▼
🤝
Phase B — Contracting & Procurement
Assign contractors, issue work orders, allocate BOQ, procure materials
▼
08
Contractor Selection & Work Order
Select contractors/sub-contractors from the Supplier module. Assign to BOQ items via contractor field. Define contractor unit prices separately from estimated prices. Work order = contract scope + rates.
PM + Costing Mgr BOQItem.contractor
batch-assign-contractor
▼
09
BOQ Allocation to Sub-Projects
Master BOQ items are allocated to block-level sub-projects with specific quantities. Tracks allocatedQuantity vs remainingQuantity. Prevents over-allocation beyond estimated quantity.
Costing Manager (MRM) POST /boq/allocate
▼
10
Material Requisition (MR)
Site engineer raises MR for materials needed. This is MRM's "Material Requisition" input. Linked to specific BOQ items so material cost is tracked against budget.
Site Engineer Indents / MR module
▼
11
Purchase Order (PO) → GRN → Material Issue
MR triggers PO creation from BOQ items. Vendor delivers → GRN recorded in Store. Materials issued to site. BOQ tracks orderedQuantity and receivedQuantity. Updates totalCommitted on project.
Procurement + Store POST /boq/create-po
PurchaseOrder model
▼
⚒️
Phase C — Site Execution & Daily Monitoring
Track daily progress, record expenses, update task completion, site photos
▼
12
Daily Progress Report (DPR)
Site engineer submits DPR with: weather, workforce count (civil, electrical, plumbing, supervisors), work done per task, materials used, issues/risks, and up to 20 site photos. MRM's DPR concept mapped directly.
Site Engineer DailyProgressReport.create()
POST /dpr (multipart)
▼
13
Task Progress & Physical Verification
Update progressPercent per task. Tasks support physical verification (isPhysicallyVerified, verificationPhotoUrl). Progress auto-rolls up: Task % → Project % → Zone % → Master %.
Site Eng + QA/QC PUT /tasks/:taskId
syncProjectProgress()
▼
14
Record Expenses
Track all project expenses by category (Civil, Electrical, Plumbing, Labor, Materials, etc.). Payment status tracking: Pending → Approved → Paid. Auto-updates totalActualSpent on project.
PM / Finance ProjectExpense.create()
syncProjectActuals()
▼
Quality Inspection Gate (QA/QC)
✓ Certified → Proceed to Billing ✗ Failed → Rework Required
▼
🧾
Phase D — Contractor Billing & IPC
RA Bill → IPC generation → Cheque request → Payment (MRM's core output)
▼
15
Contractor Running Bill (RA Bill) → IPC Generation
Contractor submits running bill. Costing Manager creates Subcontractor IPC invoice selecting BOQ items with currentQuantity executed. System auto-calculates: previous qty + current qty = cumulative. Validates cumulative ≤ BOQ estimated quantity (no over-billing). Deductions: Retention % + Advance Recovery + WHT % = netPayableAmount.
Costing Manager (MRM) ProjectInvoice.create()
type: 'Subcontractor_IPC'
▼
IPC Approval Gate (PM + Director)
✓ Approved → Finance processes payment ✗ Rejected → Revise bill
▼
16
Cheque Request & Payment
MRM's "Cheque Request" input. Finance generates payment against approved IPC. Payment tracked via paidAmount, paidDate, paymentMethod, paymentReference. Invoice status: Draft → Submitted → Approved → Paid. Updates contractor ledger and totalActualSpent.
Finance + Director PUT /invoices/:id
{ status: 'Paid' }
▼

Abstract of Cost & Real-Time Reports
All data feeds into automated reports. The system already computes: totalEstimatedCost vs totalActualSpent (variance), totalCommitted (PO amounts), totalInvoiced (IPCs), overallProgress (%), and per-BOQ-item costVariance and quantityVariance. The Executive Rollup API aggregates everything from block → zone → master level.
